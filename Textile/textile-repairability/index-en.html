EU DPP Textile Repairability Ontology: Description back to ToC

The module reuses the semantic product-event classes defined in the EU DPP EVENT module. Textile-specific life-extension event classes bridge those event semantics with concrete textile process executions; EPCIS technical carriers remain defined by the EVENT module.

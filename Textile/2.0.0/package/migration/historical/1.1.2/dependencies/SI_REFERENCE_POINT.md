# SI Reference Point source

The textile ontology uses a bounded MIREOT subset of the authoritative SI Reference Point knowledge model.

- Authoritative service: https://si-digital-framework.org/SI
- Knowledge-base download: https://si-digital-framework.org/SI/si.ttl
- Knowledge-model version used for this release: 1.0.0
- Source update date: 2026-06-10
- Local subset: `../mireot/si-textile-mireot.ttl`

The full SI knowledge base is not imported by the textile modules. The local subset contains only the entity declarations and supporting axioms required by the shared quantitative-value model.

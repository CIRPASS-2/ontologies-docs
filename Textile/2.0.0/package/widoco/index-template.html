EU DPP Textile Ontology

Reference documentation of the CIRPASS-2 textile ontology network for textile Digital Product Passports. The ontology network is developed for use with the EU DPP Core Ontology and is organised into specialised modules covering textile products, materials, structure, processes, durability, assessment, contextual information, indicators, repairability, recyclability and substances of concern. Each module page is generated from its canonical ontology file and includes an interactive WebVOWL graph.

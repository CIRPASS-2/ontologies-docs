EU DPP Textile Process Ontology: Description back to ToC

Process types describe categories of textile operations, while process executions represent concrete occurrences. Parameter types define the kind of operational setting involved, and parameter settings associate concrete values with an execution.

Target specifications describe intended characteristics of process outputs and remain distinct from operational controls. Product characteristics belong to the relevant product or structure module, and assessment results remain part of Textile Assessment.

The module also provides the textile-process layer used by repair, recyclability and lifecycle-event representations.

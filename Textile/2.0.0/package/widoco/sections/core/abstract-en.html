Abstract

The EU DPP Textile Core Ontology defines the central concepts used to represent textile products in a Digital Product Passport context. It covers textile product categories, fibre composition, textile apparel classification, and controlled vocabularies for textile apparel product types, fibre types, and study-scope status. The module is grounded in the JRC preparatory study on textiles and is designed to be used as part of the wider modular textile ontology network.

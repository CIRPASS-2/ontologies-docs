EU DPP Textile Durability Ontology: Description back to ToC

Durability constructs, observed performance parameter types and failure modes are represented as OWL classes. They are not replaced by SKOS controlled values in the ontology itself, although application-specific codelists may be derived where controlled data-entry values are required.

Assessment methods, measurements, thresholds and quantitative results remain outside this module and are represented through Textile Assessment and the shared quantitative-value pattern.

Observed degradation phenomena are not declared disjoint from observed performance parameters because the same phenomenon may also function as an inspection parameter in a particular assessment context.

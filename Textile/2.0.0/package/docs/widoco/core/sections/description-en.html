EU DPP Textile Core Ontology: Description back to ToC

Fibre type concepts also instantiate CORE MAT MaterialType. The hasFibreType property specializes CORE hasMaterialType: a fibre composition entry, already a MaterialOfComposition, is linked to its classification. The product-to-entry relation remains distinct. These project-approved alignments address Nader Jelassi's PR #19 review; the JRC study does not prescribe these OWL axioms.

Fibres, yarns and fabrics are modelled as textile products. When one textile product is incorporated into another product, the component role is represented through the DPP component relation rather than by introducing a separate intermediate-product class.

Textile apparel product categories and named fibre types are represented as SKOS controlled concepts rather than OWL subclasses. This allows the ontology to distinguish product classification values from the ontological classification of textile products themselves.

Study-scope concepts are used to indicate whether particular textile product types fall within the scope of the JRC preparatory study. This scope information does not alter their classification as textile products.

Stable local notations are provided for controlled concepts to support data exchange, mapping and validation.

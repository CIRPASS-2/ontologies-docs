EU DPP Textile Indicator Ontology: Description back to ToC

An indicator is not used as a generic container for every numerical or assessment result. Raw results remain assessment results, while thresholds remain assessment criteria and numerical magnitudes use the shared quantitative-value model.

The module deliberately does not subclass the current DPP QualityIndicator class because that class is modelled as a quantitative property in the inspected DPP Core. Reusing it here would conflate the interpretive indicator layer with the quantitative-value model used by the textile ontology network.

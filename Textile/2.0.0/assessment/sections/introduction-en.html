The Textile Assessment module provides the common assessment framework used by the textile ontology network. It distinguishes reusable assessment methods and standards from concrete assessment executions and from the results produced by those executions.

The module also represents assessment conditions, parameter settings, interpretation scales, endpoints and performance thresholds. Quantitative results, settings and thresholds use the shared txtcon:QuantitativeValue pattern and SI Digital Framework resources provided through the Textile Connector.
